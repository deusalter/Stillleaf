# BooksPresence app icon

`BooksPresence.png` is the 1254px RGBA source artwork. `BooksPresence.icns` contains the standard macOS 16px through 1024px representations generated from that source with `sips` and `iconutil`.

Artwork was generated with the built-in image generation tool using a macOS-style deep-plum rounded-square tile, a dimensional burgundy hardbound book, warm ivory page edges, and a copper bookmark ribbon. The prompt required transparent alpha outside the tile, no text, and no bright blue.
