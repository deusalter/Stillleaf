# Decorative cover art

These five SVG jackets are original procedural/vector artwork authored for the Stillleaf website. Their titles are fictional decorative elements, not claims about published books, authors, available EPUBs, or the user's library. No external images, copied book jackets, or author names are used.

Each jacket has a `300 × 440` viewBox and uses system Georgia with a serif fallback. The restrained artwork and large title lettering are designed for the website's small, dimensional book objects; the parent component supplies the book spine and page edges.

- `tidelines.svg`: ivory ocean contours on deep navy.
- `little-things.svg`: a botanical branch on dusty coral.
- `quiet-hours.svg`: leaves and a crescent moon on forest green.
- `wandering.svg`: a sunlit landscape framed by an arch.
- `blue-hour.svg`: silver orbital geometry on periwinkle.

The common art direction pairs spacious serif typography with a different natural rhythm on each jacket: water, growth, night, travel, and orbit. Fine inset borders add a quiet impression of stamped cloth without raster textures or expensive SVG filters.
